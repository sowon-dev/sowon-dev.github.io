## server 종료하기

  * 명령어 : `Ctrl + c`
  * 추천 검색어 : how to exit server git bash

## `git log`, nano 편집기 나가기

  * `q`

## vi편집기 나가기

  * `:wq` : write and quit(저장하고 나가기의 줄임말)

## SQL에서 리눅스로 나가기

  * `i` : sql -> 리눅스
  * `exit` : 리눅스 -> sql
