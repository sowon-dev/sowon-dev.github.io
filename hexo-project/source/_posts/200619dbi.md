## CUI환경 VS GUI환경

### GUI(Graphic User Interface)

문자가 아닌 그래픽 위주로 이루어진 방식을 말하며 현재의 우리가 쓰고있는 환경을 말한다.  
운영체제에서 작업할때 명령어 대신 아이콘을 더블클릭하여 사용하는 등 그래픽으로 데이터를 처리하는 환경이다.

### CUI(Character User Interface)

문자로 이루어진 화면을 말한다. Dos환경일때 그래픽이 아닌 명령어(문자)로 처리하는 환경이다.  
그렇다면 CUI환경에서 문서를 어떻게 작성하고 저장할까?  
**VI편집기(브이아이에디터)를 사용하면된다.**

  
  
  

## VI 에디터

VI편집기는 다른 에디터와 다르게 모드형 편집기이고 총 3가지모드로 구성되어있다.

  * 명령모드
  * 입력모드
  * ex명령모드

![VI편집기 주요 단축키1](https://t1.daumcdn.net/cfile/tistory/99F021445BE41A3C1F?download)

![VI편집기 주요 단축키2](https://img1.daumcdn.net/thumb/R1280x0/?scode=mtistory2&fname=http%3A%2F%2Fcfile26.uf.tistory.com%2Fimage%2F99E7C9505BE41B8727B5AA)

명령모드에서 편집모드로 가기 - i  
편집모드종료 후 명령모드 esc  
편집모드에서 저장하기 :w  
편집모드에서 저장하고 나가기 - :wp  
편집모드에서 저장하지 않고 나가기 - :p!

  
  
  

## 리눅스명령어

  1. 명령어 잘못 실행시켰을때 : `ctrl+z`를 누르면 stop이 된다.

  2. 폴더복사할때 : 다른 경로로 동일한파일명을 복사하고싶을때는 새로운 파일명을 점(.)을 찍어주면 원본과 동일한 이름으로 복사된다

```plain
$] cp 복사하고싶은파일명.txt 복사할경로/.
```
