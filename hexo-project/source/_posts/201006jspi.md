## 컴파일에러 VS 런타임에러 차이

  * 컴파일에러 : 컴파일시 발생하는 에러, IDE의 빨간줄 에러
    * 컴파일이란 개발자가 작성한 고급언어를 기계어로 바꾸어주는 것
  * 런타임에러 : 프로그램 실행시 발생하는 에러, IDE의 노란줄 에러
    * RUN 버튼 클릭 후, 즉 프로그램 실행 후 CONSOLE에 나타나는 에러
