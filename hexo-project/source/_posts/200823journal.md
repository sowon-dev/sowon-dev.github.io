## 코드러너

vscode에서 크롬개발자도구처럼 간단한 출력값을 바로 보고 싶을때가 있다.  
이때 사용하면 좋을 익스텐션이 바로 [코드러너 (공식사이트)](https://marketplace.visualstudio.com/items?itemName=formulahendry.code-runner) 이다.

![](https://github.com/formulahendry/vscode-code-runner/raw/master/images/usage.gif)

예시는 파이썬이지만 js등 다른 언어도 충분히 가능하다.

  * 다운로드 : vscode extension에서 code runner 검색 후 다운로드

  * 사용법 : ctrl + alt + N 

    * output에 바로 출력결과를 확인 가능.
