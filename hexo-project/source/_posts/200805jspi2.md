## setInterval() 와 clearInteval() 함수

  1. setInterval(“스크립트 실행문”,시간(밀리초)) : 일정 시간마다 코드를 실행 가능
  2. clearInteval(실행중인객체정보) : 인터벌 작업종료
     * [참고링크 : 가위바위보게임만들기](https://sowon-dev.github.io/2019/09/22/190922/)
  3. CDATA VS PCDATA 
     * CDATA (UnParsed Character DATA) : 코드가 태그를 포함하거나, 연산(부등호)를 포함할때 일반 문자로 인식하도록 처리(주로 `>`사용시 html닫는태그가 아니라 부등호연산이라는 걸 알려줌)
     * PCDATA (Parsed Character DATA) : 코드가 태그를 포함하거나, 연산(부등호)를 포함할때 코드 그대로 인식하도록 처리(주로 `>`사용시 html 닫는 태그임)
     * [참고링크 : CDATA란?](https://sdevstudy.tistory.com/6)
  4. 예제코드

```html
<head>
//1. setInterval("스크립트 실행문",시간(밀리초)) : 일정 시간마다 코드를 실행 가능
//2. clearInteval(실행중인 객체 정보) : 인터벌작업 종료
//3. CDATA : (UnParsed Character DATA) VS PCDATA (Parsed Character DATA)
	
//<![CDATA[
let i=0;
let s = setInterval("console.log(i++)",1000);
//]]>
</head>

<body>
<input type="button" value="인터벌정지" onclick="clearInterval(s);">
</body>
```
