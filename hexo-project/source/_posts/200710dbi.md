## SQL디벨로퍼(SQL Developer) 접속방법

DB를 켜고 끄는 중대한 DB관리작업은 SQL Developer에서 할 수 없다.

  * 터미널 

  1. lsnrctl start : 리스너를 작동시키는 명령어
  2. sqlplus /nolog : sql+실행시키는 명령어
  3. connect sys/oracle as sysdba : DB에 sys로 접속하는 명령어
  4. startup : DB에 sys로 로그인한 후 DB실행하는 명령어
  5. conn hr/hr : 유저 hr로 로그인
  6. 접속탭에서 초록색 + 클릭 아래 부분 중점으로 작성 후 접속 클릭
     1. 접속이름 : 원하는 이름 입력
     2. 사용자 이름 : 만들었던 유저명 입력 ex)hr
     3. 비밀번호 : 만들었던 유저 비번 입력 ex)hr
     4. SID : 사용하고 있는 DB명 입력 ex)orcl
